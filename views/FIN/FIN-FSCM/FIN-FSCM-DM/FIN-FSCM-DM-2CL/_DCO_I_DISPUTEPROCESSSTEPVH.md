# _DCO_I_DISPUTEPROCESSSTEPVH

**This CDS view provides value help for dispute processing steps. It serves as a value help provider to enable users to select valid dispute processing step values with associated text descriptions in a user-friendly manner. This CDS view provides the data to answer the following business questions: Which dispute processing steps are available in the system? What are the valid values for selecting dispute processing steps? To help you decide which CDS view to use for your purposes, SAP has introduced the annotation ObjectModel.supportedCapabilities that indicates the most appropriate use cases for each CDS view.
