# _DCO_I_DISPUTEPRIORITYVH

**This CDS view provides value help for dispute priority. It enables users to select and filter dispute priority values with text descriptions in a user-friendly manner. This CDS view provides the data to answer the following business questions: What are the available dispute priority levels in the system? Which priority should be assigned to a specific dispute? How can I filter disputes by their priority classification? To help you decide which CDS view to use for your purposes, SAP has introduced the annotation ObjectModel.supportedCapabilities that indicates the most appropriate use cases for each CDS view. To find out what use cases are best supported by this CDS view, access the entry of the CDS view in the View Browser app and find the values for this annotation under the Annotation tab. For more information, see Supported Capabilities for CDS Views.**
