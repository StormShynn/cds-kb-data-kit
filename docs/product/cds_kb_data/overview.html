Connect an AI agent via MCP

Pick the block that matches your client, copy it, paste it into your mcpServers config — no install, no API key.

For clients with native remote-MCP support (Claude Desktop/Code, recent Cursor/VS Code builds).

{
  "mcpServers": {
    "cds-kb": {
      "type": "http",
      "url": "https://cds-kb-mcp.cfapps.us10-001.hana.ondemand.com/mcp"
    }
  }
}
Copied!

For stdio-only clients: bridges the URL above over stdio via supergateway (needs Node ≥ 20 on this machine, no other install).

{
  "mcpServers": {
    "cds-kb": {
      "command": "npx",
      "args": [
        "-y",
        "supergateway@3.4.3",
        "--streamableHttp",
        "https://cds-kb-mcp.cfapps.us10-001.hana.ondemand.com/mcp"
      ]
    }
  }
}
Copied!

Public, no auth, no rate limit beyond casual-abuse protection — hosted on a SAP BTP trial, so this URL may change if the trial resets. Full options (self-hosting, OAuth, other clients) in the cds-kb-mcp README ↗.
